## Work Process Summary

For this assignment, I built my very first webpage from scratch. I decided to style it with a Spider-Man theme, using a red-and-blue color palette, a dark web-pattern background, and comic-style fonts from Google Fonts.

### Step-by-Step Implementation:
1. **HTML Structure:** Set up the basic webpage layout, added structured headings (`<h1>` to `<h3>`), an "About Me" paragraph, and created lists for my hobbies (`<ol>`) and favorite websites (`<ul>`).
2. **Media & Links:** Embedded my profile picture (`Me.PNG`), added working links to external sites, and included an action button.
3. **Tables & Form:** Built a class schedule table, created a two-column layout using tables (Menu + Content), and designed a contact form with name, email, and color inputs.
4. **CSS & Styling:** Linked an external `style.css` file. I configured colors, margins, padding, borders (Box Model), connected Google Fonts (`Bangers`), and styled the form and tables to match the Spidey aesthetic.
5. **Publishing:** Added a custom favicon (`favicon.png`) and published the completed project live using GitHub Pages.
